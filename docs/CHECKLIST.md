# Pemetaan latihan

- Pendaftaran siswa baru: formulir enam kolom sesuai studi kasus, ditambah pilihan jurusan.
- PHP server-side: halaman dan proses penambahan, pembacaan, pembaruan, penghapusan.
- Database: query PDO; skema MySQL tersedia, SQLite menjadi opsi tanpa konfigurasi.
- GET: daftar, filter, pencarian, detail, halaman form, dan konfirmasi hapus.
- POST: tambah, edit, dan hapus; semua memakai CSRF dan validasi server.
- Blog: artikel HTML, penjelasan kode, screenshot, sumber, repo, dan tautan aplikasi.
- GitHub: repository Boyeep/PWEB-PHP.
- Deploy: fungsi PHP Vercel, penyimpanan snapshot SQLite privat yang bertahan antar request.
